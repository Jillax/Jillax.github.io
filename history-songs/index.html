一课一歌

初高中历史教材，一课配几首相关的歌。南美左翼配智利的《团结人民之歌》，九一八配《松花江上》，盛唐长安配《长安姑娘》，苏联解体配维克多·崔——歌是气氛组，也是记忆锚点。

歌曲走两条线：带 ★ 的来自 B 站收藏夹「历史List」，点歌名直达原视频；不带 ★ 的是推荐曲目，链接指向 B 站、网易云的搜索页，搜不到就换个关键词。课号按统编版目录（初中 2016 版 / 高中《中外历史纲要》2019 版），不同年份版次课序略有出入。

维护方式：每册一个 JSON，在 history-songs/data/ 下；改完运行 python scripts/build_history_songs.py 重新生成本页的 data.js。想给某课补歌，丢进 B 站收藏夹或直接改 JSON 都行。
