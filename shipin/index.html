01 / WHERE

你想看什么 → 该去哪一家

先按问题定位，再进渠道。这一页的用法不是从清单第一行读起，而是找到你那句话对应的那一行，点渠道名跳到卡片。七个问题里只有两个的答案包含B站。

02 / CHANNELS

渠道清单

四组共 个入口。每条右上三个徽章依次是：花费（免费 / 部分免费 / 付费为主）、门槛（不用登录 / 需注册实名 / 需师生账号或学校订购）、可信度（已确认入口与内容形态 / 只见到线索未亲自核验）。灰底的那段是用法与坑。

03 / KEYWORDS

拆词手册：会搜不到的词，和该搜的词

同一份内容，在不同平台要用不同的话去问。划红线的是注定搜不到的问法，绿底的是有效关键词——点一下可以直接复制。

04 / UNVERIFIED

我没能核实的部分

一份渠道清单如果不写自己哪里没验过，就是在暗示全都可靠。以下 条是这一页的真实边界，其中 标 verify 的渠道不要当确定入口使用。

05 / RELATED

这一页该和谁一起用

渠道地图给出的是「在哪里看」，但要真正定位到某一节具体的课，需要先知道是谁上的、在哪张名录里。按人名搜，是打通两页的关键。
